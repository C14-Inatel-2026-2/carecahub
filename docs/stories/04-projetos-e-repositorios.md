# US-04 — Cadastro de projetos e repositórios

Como líder de grupo, quero cadastrar e manter o projeto e o repositório do meu grupo, para registrar o trabalho que será desenvolvido e acompanhado no CarecaHub.

## Critérios de aceite

- Dado que sou líder de um grupo, quando crio um projeto com os dados obrigatórios preenchidos, então o projeto deve ficar associado ao meu grupo.
- Dado que o grupo possui um projeto, quando cadastro a URL de um repositório válido, então o repositório deve ser exibido nos detalhes do projeto.
- Dado que sou líder do grupo, quando altero o nome ou a aparência permitida do projeto, então a página do projeto deve apresentar a nova configuração.
- Dado que não faço parte do grupo responsável, quando tento alterar seu projeto ou repositório, então a operação deve ser negada.
- Dado que existe um projeto cadastrado, quando um usuário autorizado o consulta, então deve visualizar seus dados e integrantes do grupo.
